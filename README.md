# FridgeBrain — Frontend Prototype

A clickable prototype for a household grocery management app. Open `index.html` in any browser — no server required.

## Screens

| Screen | Description | Access |
|--------|-------------|--------|
| Login/Signup | Sign in or create account (any credentials work) | Default when logged out |
| Home | To-buy list with household selector | Default when logged in |
| Inventory | Current household items with category filters | Hamburger menu |
| Receipt Scanner | Upload/scan receipts, auto-parse items | Hamburger menu |
| Cost Splitting | Track and settle shared expenses | Hamburger menu or receipt screen |
| Activity | Chronological feed of household actions | Hamburger menu |
| Profile & Settings | User info, households, notifications, stores | Hamburger menu or avatar |

## Navigation

- **Hamburger menu** (☰ top left) — Access all screens
- **Avatar** (top right) — Go to Profile & Settings
- **Household selector** — Switch between households on Home screen
