Build a frontend prototype for a web app called FridgeBrain. 
This is a household grocery management app. Use fake/hardcoded 
mock data throughout — no real backend needed. This is a 
clickable prototype to validate the design and user flows.

---

TECH STACK:
- Single page app using HTML, CSS, and vanilla JavaScript
- All in one folder, no frameworks needed
- Must work by opening index.html in a browser
- Mobile-first design (375px wide, like an iPhone)
- Center the app on desktop inside a phone-frame container

---

DESIGN DIRECTION:
Clean, minimal, Apple-inspired. Think Robinhood meets WhatsApp.
- Background: #FFFFFF
- Primary accent color: #00C853 (fresh green — food/grocery feel)
- Secondary: #F5F5F5 for surfaces
- Text primary: #1A1A1A
- Text secondary: #757575
- Font: Use Google Fonts — "Inter" for everything
- Bottom of every screen has a hamburger menu icon top left
- No clutter. Every screen has one clear purpose.
- Generous white space
- Subtle rounded corners (12px) on all cards
- Smooth transitions between screens (fade or slide)
- The entire app lives inside a centered phone frame on desktop
  (390px wide, 844px tall, with subtle shadow and rounded corners)

SCREEN 2 — Home (default screen when logged in)
- Top bar: "FridgeBrain" logo left, profile avatar circle right
  (show initials, e.g. "EB" for Elliot Boz)
- Household selector below top bar — shows current household
  name with a dropdown arrow (e.g. "🏠 The Apartment")
  Clicking it shows two fake households to switch between:
  "The Apartment" and "Family Home"
- Section: "To-Buy List" 
  Show 5-6 fake items with:
  - Product photo (use placeholder colored squares for now)
  - Item name (e.g. "Whole Milk", "Sourdough Bread")
  - Who requested it and when (e.g. "Added by Jake · 2h ago")
  - Small checkbox to mark as bought
  - Tapping an item expands it to show notes/details

  Pressing it opens a confirmation modal:
  "Notify your household you're shopping?"
  Shows which store (fake: "Whole Foods")
  Two buttons: "Yes, notify them" and "Cancel"
  After confirming → shows success toast: 
  "Your household has been notified!"
- Empty state if list is empty: 
  "Nothing on the list yet — add something below"
  with a + button
